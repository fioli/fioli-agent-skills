# Architecture Decision Records

Decisions are recorded using [MADR 4](https://adr.github.io/madr/)
(full template for major decisions, minimal template for minor ones).
Accepted ADRs are immutable: to change a decision, write a new ADR and mark
the old one as `superseded by ADR-NNNN`.
